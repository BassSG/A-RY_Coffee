# A-RY Coffee POS

GitHub Pages แสดงแอป Google Apps Script ภายใน iframe โดยตรง ข้อมูลอยู่ใน Google Sheets แอปเปิดให้ทุกบัญชี Google ที่ลงชื่อเข้าใช้เข้าถึงโดยใช้สิทธิ์เจ้าของ ผู้ที่เข้าถึงสามารถดูและแก้ไขข้อมูลผ่านฟังก์ชันแอปได้ โปรดพิจารณาความเสี่ยงก่อนเผยแพร่ลิงก์ บางอุปกรณ์อาจบล็อกการลงชื่อเข้าใช้ใน iframe ให้เปิดลิงก์ GAS โดยตรงเพื่อลงชื่อเข้าใช้ก่อน

โฟลเดอร์ `gas/` เป็นสำเนาโค้ด GAS การแก้ GitHub ไม่ได้อัปเดต GAS อัตโนมัติ `ALLOWALL` อนุญาตให้เว็บไซต์อื่นฝังแอปได้และเพิ่มความเสี่ยง clickjacking
