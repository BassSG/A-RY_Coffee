# A-RY Coffee POS

GitHub Pages แสดงแอป Google Apps Script ภายใน iframe โดยตรง พร้อมติดตั้งหน้าเว็บเป็น PWA ได้ ข้อมูลและการทำงานยังอยู่ใน GAS และ Google Sheets ต้องเชื่อมต่ออินเทอร์เน็ตและลงชื่อเข้าใช้บัญชีเจ้าของ บางอุปกรณ์อาจบล็อกการลงชื่อเข้าใช้ใน iframe ให้ลงชื่อเข้าใช้ Google ผ่านลิงก์ช่วยเหลือแล้วกลับมาโหลดหน้าใหม่

โฟลเดอร์ `gas/` เป็นสำเนาโค้ด GAS การแก้ GitHub ไม่ได้อัปเดต GAS อัตโนมัติ `ALLOWALL` อนุญาตให้เว็บไซต์อื่นฝังแอปได้ ควรรักษาสิทธิ์การเข้าถึงของ GAS เป็น Only myself และพิจารณาการป้องกัน clickjacking เพิ่มเติม
