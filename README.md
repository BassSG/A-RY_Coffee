# A-RY Coffee POS

เว็บไซต์นี้เป็นทางเข้าแบบติดตั้งได้สำหรับระบบขาย Google Apps Script ของร้าน เปิดระบบขายด้วยปุ่มบนหน้าเว็บ ระบบขายและข้อมูลยังอยู่ใน Apps Script และ Google Sheets ของร้าน ต้องลงชื่อเข้าใช้บัญชีเจ้าของและเชื่อมต่ออินเทอร์เน็ต การติดตั้งหน้าเว็บไม่ได้ทำให้ระบบขายใช้แบบออฟไลน์หรือเปิดเป็นแอปเนทีฟได้

โฟลเดอร์ `gas/` เป็นสำเนาโค้ดล่าสุดของโปรเจกต์ Apps Script ที่ดึงมาเมื่อจัดทำรีโพนี้ การแก้ไฟล์ใน GitHub ไม่ได้อัปเดต GAS อัตโนมัติ ต้องเผยแพร่ GAS แยกต่างหาก ระวังอย่าเปิดสิทธิ์แอปเป็นสาธารณะ เพราะระบบมีข้อมูลยอดขายของร้าน

Android: เปิดเว็บด้วย Chrome แล้วเลือกติดตั้งแอป หรือเมนู ⋮ > เพิ่มลงในหน้าจอหลัก หากไม่มีปุ่มติดตั้ง ระบบขายจะเปิดในเบราว์เซอร์เมื่อกดปุ่มเปิดระบบขาย
